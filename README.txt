Presupuestador de Muebles V1.4

- Base de materiales con catálogo maestro de materiales, variantes y grosores.
- Cálculo de mueble puede seleccionar un material aunque todavía no tenga precio cargado.
- El precio aparece sólo cuando la combinación seleccionada existe en la base.
- Previsualización 3D axonométrica en Canvas, sin dependencias externas.
- Arrastrar para rotar y rueda/pinch para zoom.
- Los datos se guardan localmente en este dispositivo.
